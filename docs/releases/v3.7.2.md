# v3.7.2: Session visualisation

`/agent-handoff visualise [<receipt-file>]`, also `visualize`, opens a whole
run on one token-protected loopback page. The optional selector defaults to
the newest saved receipt. The server runs until Ctrl-C.

```bash
python3 "$HANDOFF_DIR/scripts/handoff-session-ui.py" [<receipt-file>] --repo "$REPO"
```

Use `--no-open` to print the URL and `--port` to select a port.

The overview displays a hand-authored narrative SVG as an image with checked
hotspots. Axis segments preserve gaps and non-zero viewBox origins. Lane
windows are reconciled against submitted time and exit-file mtime within 60
seconds. A failing lane loses only its own hotspot; running jobs have no
invented end. **Show hotspots** exposes alignment for a human to inspect.
The narrative prose remains unverified.

Missing lane metadata keeps the diagram and job table. A missing diagram shows
the job table and a copyable receipt-specific `baoyu-diagram` prompt carrying
the root data-attribute contract.

Transcript and cost-receipt tabs frame the unchanged shipped pages under one
origin. Session facts associate goals by jobId intersection. Unmatched goals
are explicitly disclosed as the current working-tree goal. The denial list
joins copilot events by toolCallId, retains missing starts, and names unreported
values. Anomalies come from the receipt and job state files.

The server checks Host and token on every route, passes only validated absolute
paths to renderers, and applies separate CSP policies for the shell, SVG, and
frames. Each subresource carries the token. Per-output locks cover rendering
and response reads; caches check every input's mtime. Only the existing cached
renderings are written under `.handoff/`. Receipt schema remains 6.

Tests and fixtures cover the three overview states, geometry, reconciliation,
path and authentication guards, actual response headers, association, denials,
and cache invalidation and concurrency. Visual calibration of a real generated
SVG remains a driving-session check. This release adds no generated timeline,
static sharing bundle, or cross-run aggregation.
