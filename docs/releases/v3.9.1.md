# v3.9.1: The setup wizard uses the session view's design

The web wizard that `/agent-handoff config` opens now uses the design system in `DESIGN.md`, which the session view already uses. Until this release, the wizard had its own warm look, with Avenir type, an orange accent, a hero map, a noise texture and shadows. This release removes that look. The page has one serif heading, monospace capital labels and flat cards with 1px borders. Two accents have fixed jobs: cobalt marks focus and selection, and coral marks warnings. Light and dark come from one token set, and the System, Light and Dark switch stays.

## What the page tells you

The environment strip shows all four backends. Each status pill holds a word, so the state does not depend on colour. For Claude Code and Codex, the page reads the binary version and shows FOUND or MISSING. For GitHub Copilot and Cursor, the page reads only the model list, so the pill says LISTED or NO MODELS. The Copilot CLI itself is checked at smoke. Opening the wizard runs no command that it did not run before.

The preview now comes from the engine's own file list. Each file shows its state: WRITE, DELETE, UNCHANGED or REFUSED. One row per identity follows, taken from the selection that was sent. If you change a field while a preview request runs, the page ignores the response. A failed preview has the title "Preview failed" and shows the refusal text. A line under the plan names the two writes that the list leaves out. Install keeps a backup of each changed file under `.handoff/backups/`, and the smoke check adds a verification record to `.handoff/config.toml`.

Each permission switch has a hint that says what the setting permits on that backend. With Allow all, the switch shows a coral pill. The install panel no longer says "safe defaults". It names each identity that runs with Allow all. It also names each identity on Cursor, because Cursor runs writing jobs in force mode with either setting.

## Input checks

A Cursor model is a slug in a typed field with a `<datalist>` of the `cursor-agent models` catalogue. A slug that is not in the catalogue marks the field invalid and blocks the preview. The server still refuses it too. Claude, Codex and Copilot keep their select lists, and all four show the slug first in each option.

A Custom tile joins Balanced, Quality and Cost. When a preset replaces custom settings, the status line offers Undo. A switch from one preset to another offers nothing, because it replaces no edits.

The two review-pass fields accept only a whole number of 1 or more. An invalid value shows an error under the field, linked through `aria-invalid` and `aria-describedby`, and blocks the preview. After a preview or an install, focus moves to the heading of the result.

## Known gaps

- The terminal wizard is unchanged.
- The transcript viewer and the user guide still use their own palettes.
